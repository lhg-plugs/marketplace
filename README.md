# lhg-plugs：小白专家插件市场

> **一句话介绍**：每个插件整合某垂直方向的最佳方法论与工具，让零基础小白一句话就能做出专家级成果——有确定性自查、有硬门护栏、有质量分档。
>
> **一键安装**：在 Claude Code 里运行
> ```
> /plugin marketplace add lhg-plugs/marketplace
> /plugin install <插件名>@lhg-plugs
> ```
> 也可以直接加单个插件的仓库，例如 `/plugin marketplace add lhg-plugs/lhg-ppt`。

## 什么时候用 / 什么时候不用

- **用**：你是某领域的小白，想一句话得到"专家带做"的完整流程 + 自动自查。
- **用**：你想把某个垂直方法论沉淀为团队可复用的插件。
- **不用**：你已经是该领域专家——直接调用底层 skill 或自己写命令更快。
- **不用**：学术/法律场景请先读各插件的合规声明（毕业论文=写作助手非代写；合同审查=非律师意见）。
